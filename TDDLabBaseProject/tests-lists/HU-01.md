Caso 1: - Si todos los campos (nombre, email, password) estan vacíos o en blanco -> "Por favor, completa todos los campos"
- Si falta el nombre -> "Por favor, completa todos los campos"
- Si falta el correo -> "Por favor, completa todos los campos"
- Si falta la contraseña -> "Por favor, completa todos los campos"

Caso 2:
- Correo con formato inválido 
    - debe tener @ 
    - debe tener dominio
    - debe tener usuario
    - no debe tener espacios
-> "El correo electrónico ingresado no es válido"

Caso 3:
- Contraseña con al menos 6 caracteres 
    - si tiene menos
    - si tiene menos de 6 ignorando espacios en los extremos
-> Sino, "La contraseña debe tener al menos 6 caracteres"

Caso 4:
- Nombre con al menos 2 caracteres válidos 
    - si tiene menos
    - si tiene una letra rodeada de espacios
-> Si es menor a 2 letras: "El nombre debe tener al menos 2 caracteres"

Caso 5:
- Datos correctos -> "¡Cuenta creada exitosamente! Bienvenido a HomeBound" y limpiar formulario  s
