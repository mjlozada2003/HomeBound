# Lista de Pruebas - HU-07: Generar link de publicación

## Criterios de Aceptación
1. [ ] **Botón "Compartir":** Disponible en la vista de detalle de cada publicación.
2. [ ] **Copia al portapapeles y notificación:** Al presionar el botón "Compartir", se copia la URL única de la publicación al portapapeles y se muestra el mensaje de confirmación: `"Enlace copiado. ¡Compártelo en tus redes!"` con fondo verde claro y checkmark.
3. [ ] **Apertura directa (Deep Linking):** Al abrir el enlace generado (ej. `?id=pub-123`), la aplicación carga y muestra automáticamente el detalle de esa publicación (depende de HU-12).

---

## Casos de Prueba (Ciclo 1: Lógica del enlace único - Model / Helper)

### Caso 1: Generación del enlace único
- [ ] **Generación exitosa:** Dado un ID de publicación válido (`"pub-101"`) y una URL base (`"https://homebound.app/"`), genera `"https://homebound.app/?id=pub-101"`.
- [ ] **Preservación de ruta:** Si la URL base ya tiene ruta (ej. `"http://localhost:1234/index.html"`), genera `"http://localhost:1234/index.html?id=pub-101"`.
- [ ] **ID vacío o inválido:** Si se pasa un ID nulo, vacío o que solo contiene espacios, retorna una cadena vacía `""`.
- [ ] **Uso de window.location:** Si no se especifica URL base en el entorno de navegador, toma la URL actual de `window.location`.

### Caso 2: Extracción del ID de publicación desde la URL
- [ ] **Extracción desde query param `?id=`:** Dada una URL como `"https://homebound.app/?id=pub-101"`, extrae correctamente `"pub-101"`.
- [ ] **Parámetros adicionales:** Si la URL contiene otros query params (ej. `"https://homebound.app/?tema=claro&id=pub-101"`), extrae `"pub-101"`.
- [ ] **URL sin parámetro `id`:** Retorna `null` si no existe el parámetro `id`.
- [ ] **URL vacía o malformada:** Retorna `null` ante entradas no válidas sin lanzar excepciones.

---

## Casos de Prueba (Ciclo 2: Botón Compartir, Copia y Notificación - Presenter & View)

### Caso 3: Renderizado del botón Compartir
- [ ] Renderiza el botón `#btn-compartir` en el detalle con su icono SVG y texto "Compartir".
- [ ] Contenedor o elemento de notificación `#mensaje-enlace-copiado` preparado en el DOM (inicialmente oculto).

### Caso 4: Interacción y copia al portapapeles
- [ ] Al hacer click en `#btn-compartir`, invoca `navigator.clipboard.writeText` con la URL única generada.
- [ ] Muestra el mensaje con clase `.toast-enlace-copiado` conteniendo el icono de checkmark `✓` y el texto `"Enlace copiado. ¡Compártelo en tus redes!"` según el diseño visual solicitado.
- [ ] Manejo si el portapapeles falla (fallback sin romper la experiencia).

---

## Casos de Prueba (Ciclo 3: Apertura directa mediante URL / Deep Linking)

### Caso 5: Detección y navegación al cargar la app
- [ ] Al inicializar la app, si la URL contiene `?id=pub-101`, consulta la publicación con `buscarPublicacionPorId('pub-101')`.
- [ ] Si la publicación existe, activa `#seccion-detalle`, renderiza sus datos y oculta las demás vistas.
- [ ] Si la publicación no existe o el ID es inválido, permanece en la vista por defecto (lista pública) mostrando un aviso adecuado.
