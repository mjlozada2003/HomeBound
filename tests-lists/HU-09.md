# Lista de Pruebas - HU-09: Gestionar mis publicaciones (editar/borrar)

## Casos de prueba (Lógica de negocio - Model)
Archivo: `src/models/Posts/misPublicaciones.test.js`

1. **Autor reconocido:** `esAutor` devuelve `true` si el correo del usuario es el `autor` de la publicación.
2. **Correo normalizado:** Reconoce al autor aunque el correo tenga mayúsculas o espacios.
3. **Otro usuario:** Un usuario que no es el autor no tiene permiso.
4. **Sin sesión:** Si no hay usuario, no hay permiso.
5. **Publicación sin autor:** Si la publicación no tiene `autor` (publicaciones antiguas), nadie tiene permiso, aunque el usuario tenga correo vacío.
6. **Asignar autor:** `asignarAutor` agrega a la publicación nueva el correo normalizado del usuario como `autor`.
7. **Sin modificar el original:** `asignarAutor` devuelve una copia y no cambia la publicación recibida.
8. **Solo mis publicaciones:** `obtenerMisPublicaciones` devuelve solo las publicaciones del usuario, de la más reciente a la más antigua.
9. **Formato de tarjeta:** Cada publicación incluye foto, título, fecha, tipo, colección, descripción y el estado de revisión (`"Pendiente de revisión"` o `"Publicada"`).
10. **Estado rechazada:** Una publicación rechazada muestra el estado `"Rechazada"`.
11. **Sin publicaciones:** Si el usuario no tiene publicaciones, devuelve una lista vacía y el mensaje `"Aún no tienes publicaciones"`.
