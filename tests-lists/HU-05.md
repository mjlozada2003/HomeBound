# Lista de Pruebas - HU-05: Buscar por filtro y ordenar

## Criterios de Aceptación
1. [x] Barra de búsqueda por texto.
2. [x] Filtros desplegables de categoría (con más categorías de objetos y campo de texto libre al elegir "Otro" en mascotas) y de fecha.
3. [x] Los resultados se actualizan al aplicar un filtro.
4. [x] Opción para ordenar por "Más recientes" o "Relevancia".
5. [x] Si no hay resultados, se muestra un mensaje en español.

---

## Casos de Prueba (Model: busqueda.js)

### Caso 1: Normalización del texto
- [x] Pasa a minúsculas, quita tildes y espacios repetidos.
- [x] Sin texto (undefined o null) -> ''.

### Caso 2: Búsqueda por texto
- [x] Sin texto o solo espacios -> acepta todas las publicaciones.
- [x] Encuentra por nombre (título) sin importar mayúsculas ni tildes.
- [x] También busca en la descripción y en la categoría libre ("Otro").
- [x] Todas las palabras escritas deben aparecer.

### Caso 3: Filtro de categoría
- [x] Sin categoría -> acepta todas.
- [x] Filtra por OBJETO, MASCOTA u OTRO.
- [x] Objetos tiene más categorías: Electrónicos, Documentos y tarjetas, Llaves, Billeteras y bolsos, Mochilas y maletas, Ropa y accesorios, Joyas y relojes, Lentes.
- [x] Mascotas tiene: Perro, Gato, Ave y Otra mascota.
- [x] Las subcategorías se reconocen por palabras clave del título, la descripción y la categoría libre.
- [x] "Otra mascota" sin texto libre -> mascotas que no son perro, gato ni ave.
- [x] "Otra mascota" con texto libre -> mascotas que contienen ese texto.
- [x] Una subcategoría que no corresponde a la categoría se ignora.

### Caso 4: Filtro de fecha
- [x] Sin rango -> cualquier fecha.
- [x] Hoy, últimos 7 días y últimos 30 días.
- [x] Con un rango elegido, una publicación sin fecha no aparece.

### Caso 5: Relevancia
- [x] Coincidir en el título da más puntaje que en la descripción.
- [x] Sin texto de búsqueda -> puntaje 0.

### Caso 6: Buscar, filtrar y ordenar
- [x] Por defecto se ordena por más recientes.
- [x] "Relevancia" ordena por puntaje y desempata por fecha más reciente.
- [x] Se combinan texto, categoría y fecha.
- [x] Si nada coincide -> lista vacía.
- [x] No modifica la lista original.

### Caso 7: Resumen y filtros activos
- [x] Describe la cantidad de resultados en español ("1 publicación encontrada", "3 publicaciones encontradas").
- [x] Indica si hay algún filtro aplicado (el orden no cuenta como filtro).

## Casos de Prueba (Model: publicaciones.js)
- [x] Los filtros se aplican solo sobre publicaciones visibles (aprobadas o resueltas vigentes).
- [x] Filtra por categoría, ordena por más recientes y devuelve el total de resultados.
- [x] Sin resultados por los filtros -> "No encontramos publicaciones con esos filtros. Prueba con otras palabras o quita algún filtro."
- [x] Sin publicaciones visibles -> "Aún no hay publicaciones".

## Casos de Prueba (Presenter: filtrosPresenter.js)
- [x] Las opciones de subcategoría muestran más categorías de objetos y "Otra mascota".
- [x] "Otro" y "Todas" no tienen subcategorías.
- [x] Lee todos los controles; ignora la subcategoría y el texto libre si están ocultos.
- [x] Al cambiar la categoría se muestran sus subcategorías y se actualizan los resultados.
- [x] Al elegir "Otra mascota" aparece el campo de texto libre.
- [x] La búsqueda por texto se aplica al dejar de escribir (300 ms).
- [x] Cambiar el orden o la fecha actualiza los resultados.
- [x] Si la barra de filtros no existe, no falla.
