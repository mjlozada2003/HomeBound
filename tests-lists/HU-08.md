# Lista de Pruebas - HU-08: Ver estadísticas básicas (Admin)

## Casos de prueba (Lógica de negocio - Model)
Archivo: `src/models/Stats/estadisticas.test.js`

1. **Activas:** `calcularEstadisticas` suma las publicaciones activas (`APROBADA`) de hallazgos y pérdidas y devuelve el detalle por tipo y el total.
2. **Resueltas:** Suma las publicaciones resueltas (`RESUELTA`, estado que marca HU-11) de hallazgos y pérdidas.
3. **Sin publicaciones:** Si no hay conteos, todos los contadores quedan en 0.
4. **Caso inválido - usuario normal:** Un usuario con rol `USER` recibe el error `"No tienes permisos de administrador"`.
5. **Caso inválido - sin sesión:** Si no hay usuario, lanza el mismo error.
