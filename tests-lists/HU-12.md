# Lista de Pruebas - HU-12: Ver detalle de publicación

## Criterios de Aceptación
1. [x] Al seleccionar una tarjeta de la lista se abre el detalle de la publicación.
2. [x] El detalle muestra foto, título, descripción, categoría, fecha, tipo (Perdido/Encontrado) y estado.
3. [x] Si la persona indicó contacto, se muestra su WhatsApp (con enlace directo) y su correo electrónico.
4. [x] Hay un botón para volver a la lista.

---

## Casos de Prueba (Lógica de Negocio - Model: Ciclo 1)

### Caso 1: Obtención de publicación por ID
- [x] **Búsqueda exitosa:** Dada una lista de publicaciones y un ID existente, devuelve el objeto de la publicación coincidente.
- [x] **ID inexistente o lista vacía:** Si el ID no existe en la lista o la lista es vacía, devuelve `null`.
- [x] **ID no proporcionado o inválido:** Si se pasa un ID nulo, vacío o no string, devuelve `null`.

### Caso 2: Formateo de detalle completo de publicación
- [x] **Datos obligatorios y etiquetas:** Formatea correctamente `id`, `foto` (primera foto o cadena vacía), `fotos` (arreglo completo), `titulo`, `descripcion`, `categoria`, `fecha`, `tipoTexto` (`"Encontrado"` para HALLAZGO, `"Perdido"` para PERDIDA) y `estadoTexto` (`"Activo"`).
- [x] **Contacto con WhatsApp:** Si la publicación incluye número o enlace de WhatsApp, formatea el enlace directo a WhatsApp (ej. `https://wa.me/59171234567` o el enlace provisto).
- [x] **Contacto con Correo:** Si incluye correo de contacto, prepara la dirección y el enlace `mailto:`.
- [x] **Publicación sin contacto específico:** Si no se proporcionaron contactos, los campos de contacto se devuelven vacíos sin romper el objeto.
- [x] **Ubicación y categoría detallada:** Formatea `ubicacion` y `enlaceMapa` para Google Maps y maneja categoría personalizada (`categoriaOtra`).

---

## Casos de Prueba (Capa de Servicio - Service: Ciclo 2)
- [x] **Consulta en Firestore:** `buscarPublicacionPorId(id)` busca y retorna el documento en la colección de publicaciones.
- [x] **Manejo de inexistencia o errores:** Retorna `null` si el documento no existe o si ocurre un fallo en Firestore.

---

## Casos de Prueba (Capa de Presentación y Vista - Presenter & View: Ciclo 3)
- [x] **Renderizado de vista según maqueta visual:** Presenta dos columnas (tarjeta con foto a la izquierda; badges, título verde, descripción, caja blanca de datos con iconos de calendario, ubicación y teléfono a la derecha). Nota: el botón Compartir se reserva para HU-07.
- [x] **Badge y fecha según tipo:** Muestra `PERDIDO` (rojo óxido) con "Se perdió el [fecha]" o `ENCONTRADO` (verde esmeralda) con "Se encontró el [fecha]".
- [x] **Enlaces directos:** WhatsApp abre chat y correo abre cliente de correo `mailto:`.
- [x] **Navegación e integración:** Botón `← Volver a la lista` regresa a la lista pública ocultando la vista de detalle.
- [x] **Seguridad XSS:** Todo dato renderizado en la plantilla HTML es debidamente escapado contra ataques XSS.
