# Lista de Pruebas - HU-12: Ver detalle de publicación

## Criterios de Aceptación
1. Al seleccionar una tarjeta de la lista se abre el detalle de la publicación.
2. El detalle muestra foto, título, descripción, categoría, fecha, tipo (Perdido/Encontrado) y estado.
3. Si la persona indicó contacto, se muestra su WhatsApp (con enlace directo) y su correo electrónico.
4. Hay un botón para volver a la lista.

---

## Casos de Prueba (Lógica de Negocio - Model)

### Caso 1: Obtención de publicación por ID
- **Búsqueda exitosa:** Dada una lista de publicaciones y un ID existente, devuelve el objeto de la publicación coincidente.
- **ID inexistente o lista vacía:** Si el ID no existe en la lista o la lista es vacía, devuelve `null`.
- **ID no proporcionado o inválido:** Si se pasa un ID nulo, vacío o no string, devuelve `null`.

### Caso 2: Formateo de detalle completo de publicación
- **Datos obligatorios y etiquetas:** Formatea correctamente `id`, `foto` (primera foto o cadena vacía), `fotos` (arreglo completo), `titulo`, `descripcion`, `categoria`, `fecha`, `tipoTexto` (`"Encontrado"` para HALLAZGO, `"Perdido"` para PERDIDA) y `estadoTexto` (`"Activo"`).
- **Contacto con WhatsApp:** Si la publicación incluye número o enlace de WhatsApp, formatea el enlace directo a WhatsApp (ej. `https://wa.me/59171234567` o el enlace provisto).
- **Contacto con Correo:** Si incluye correo de contacto, prepara la dirección y el enlace `mailto:`.
- **Publicación sin contacto específico:** Si no se proporcionaron contactos, los campos de contacto se devuelven como `null` sin romper el objeto.
